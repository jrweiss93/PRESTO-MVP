# Guía de código — frontend/src/features

Cada carpeta agrupa una funcionalidad completa: páginas, componentes y estado local.

## Features

| Carpeta | Qué hace |
|---|---|
| `auth` | Sesión, login, registro con identidad simulada, recuperación, verificación y perfil/KYC. |
| `wallet` | Dashboard y billetera del usuario. |
| `payments` | Depósitos, retiros y transferencias. |
| `budgets` | Presupuestos y clasificación de gastos. |
| `marketplace` | Marketplace de ofertas para prestatarios y gestión de ofertas para prestamistas. |
| `loans` | Préstamos, detalle, chat y reseñas/reputación. |
| `investments` | Productos de plazo fijo y posiciones. |
| `notifications` | Bandeja de avisos y preferencias. |
| `assistant` | Interfaz de Presti: chat, mercado, noticias y marco legal. |
| `marketing` | Landing pública y legales. |
