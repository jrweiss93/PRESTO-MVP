# Guía de código — frontend/src/features/loans/components

Componentes de interacción del préstamo.

| Archivo | Qué hace |
|---|---|
| `LoanChat.tsx` | Chat privado entre las partes; refresca cada 8 segundos y al enfocar la ventana. |
| `LoanReviewCard.tsx` | Permite recomendar o no a la contraparte y muestra su porcentaje de reputación. |
| `ReputationPanel.tsx` | Panel del perfil con el resumen de recomendaciones y las reseñas recibidas. |
