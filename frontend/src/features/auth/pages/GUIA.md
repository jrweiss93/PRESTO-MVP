# Guía de código — frontend/src/features/auth/pages

Pantallas de la feature.

| Archivo | Qué hace |
|---|---|
| `Login.tsx` | Formulario de inicio de sesión. |
| `Register.tsx` | Alta en dos pasos con DNI, credencial y rostro simulados. |
| `ForgotPassword.tsx` | Solicitud de reseteo de contraseña. |
| `ResetPassword.tsx` | Nueva contraseña desde token. |
| `VerifyEmail.tsx` | Confirmación de email. |
| `Profile.tsx` | Perfil, KYC, biometría, respaldo, seguridad y reputación. |
