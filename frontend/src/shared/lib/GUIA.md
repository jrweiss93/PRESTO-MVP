# Guía de código — frontend/src/shared/lib

Utilidades compartidas sin dependencia de una feature.

## Archivos

| Archivo | Qué hace |
|---|---|
| `decimal.ts` | Aritmética exacta con `bigint`; no usa `float`. |
| `format.ts` | Formato de moneda, tasa, fecha y etiquetas. |
| `features.ts` | Flag de Presti por entorno. |
| `profiles.ts` | Tipos y etiquetas de perfil. |
| `useIdempotencyKey.ts` | Clave estable por intento. |
| `index.ts` | `cn` con clsx + tailwind-merge. |
| `decimal.test.ts` | Tests de aritmética. |
| `format.test.ts` | Tests de formato. |
