# Guía de código — frontend/src/shared

Código transversal reutilizado por todas las features.

## Archivos

| Archivo | Qué hace |
|---|---|
| `api` | Cliente HTTP, endpoints y tipos generados. |
| `lib` | Formato, decimales, perfiles e idempotencia. |
| `ui` | Íconos, mascota y toggle de tema. |

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `api/` | Acceso tipado a la API. |
| `lib/` | Utilidades puras. |
| `ui/` | Componentes visuales. |
