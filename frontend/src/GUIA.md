# Guía de código — frontend/src

Organización de la SPA: composición, features, shared y setup de tests.

## Archivos

| Archivo | Qué hace |
|---|---|
| `index.css` | Tailwind, tema visual, dark mode, componentes semánticos y animaciones. |
| `vite-env.d.ts` | Tipos de variables de entorno de Vite. |
| `test/setup.ts` | Configuración de Testing Library. |

## Subcarpetas

| Carpeta | Contenido |
|---|---|
| `app/` | Rutas, layout y providers. |
| `features/` | Pantallas por dominio. |
| `shared/` | API, lib y UI compartida. |
| `test/` | Setup de tests. |
