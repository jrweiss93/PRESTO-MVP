# Guía de código — docs

Documentación del proyecto, ADRs, guías de demo y material de presentación. Los archivos `.md` son la fuente; `.pdf`/`.docx`/`.pptx` son versiones para compartir.

## Archivos

| Archivo | Qué hace |
|---|---|
| `architecture.md` | Mapa del backend y decisiones de capas. |
| `implementacion.md` | Detalle técnico de modelos, servicios, API, front y deploy. |
| `decisiones-tecnicas.md` | Narrativa de decisiones de código y POO. |
| `mapa-repositorio.md` | Recorrido carpeta por carpeta. |
| `mvp.md` | Arranque local y guion de demo. |
| `deploy-demo.md` | Despliegue de la demo. |
| `entrega.md` | Mapa de entrega del proyecto. |
| `regulatorio-bcra.md` | Pendientes legales y PLA/FT. |
| `audit-final.md` | Auditoría técnica. |
| `presentacion-*` | Presentaciones y versiones imprimibles. |
| `assets/` | Logo y QR de la demo. |
