01 · CONTEXTO

El problema

  • Pedir un préstamo suele ser lento, con requisitos poco claros y costos que aparecen al final.
  • Ahorrar en pesos es difícil y la inversión parece reservada a especialistas.
  • Las herramientas están separadas: banco, billetera, planilla y app de inversión.
  • Quien tiene dinero para prestar no encuentra un lugar simple con reglas claras.
La claridad también es parte del producto.

Una sola aplicación para mover, prestar, invertir y ordenar.

09 · TECNOLOGÍA

¿Por qué estas herramientas?

Python + Django

Orden, seguridad y velocidad para reglas de dinero.

PostgreSQL

Consistencia y transacciones para datos financieros.

Redis + Celery

Tareas diarias sin bloquear la aplicación.

React + Vite

Interfaz rápida y pensada primero para celular.

Docker + Render + Vercel

Despliegue reproducible y demo accesible.

Se eligieron herramientas probadas y mantenibles, no las de moda.
